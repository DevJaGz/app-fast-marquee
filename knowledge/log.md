- **Creation** (`12.x` branch): Added [zone.js Doesn't Reliably Patch requestIdleCallback/ResizeObserver/MutationObserver](lessons/zonejs-async-api-gaps.md) — the real root cause behind three unrelated-looking e2e failures during the [`adapt-12x-line`](../openspec/changes/adapt-12x-line/) apply: callbacks from these APIs can execute outside the Angular zone under `zone.js 0.11.4`, so `markForCheck()` alone marks a view dirty without triggering the tick that flushes it. Fixed by wrapping the adapter's `onMeasured`/`onUpdated`/reduced-motion-source callbacks and the demo app's idle-callback handler in `NgZone.run(...)`. Confirmed via `ng.getComponent()` in a real browser (component state updated, DOM stayed stale); not reproducible on the zoneless `20.x` line by construction. Indexed in [lessons/index.md](lessons/index.md).
- **Update** (`12.x` branch): [Branch Model and Two-Version-Line Publishing Strategy](decisions/branch-model-version-lines.md) — added a "`12.x` branch state" section recording the `adapt-12x-line` change's implementation: Angular `12.0.5`/TypeScript `4.2.4` on Node `14.21.3`, npm-based; library `version` `12.0.0`, `peerDependencies` `>=12.0.0 <20.0.0`; and discoveries that amend the change's own design — (1) under Ivy a component's declaring `NgModule` is fixed at compile time, so `NgxFastMarqueeModule` cannot bundle the idle-callback guard _optionally_, and the `no-idle-guard` e2e scenario (which also reproduces a crash specific to Angular's own `@defer`, absent from Angular 12) is dropped on this branch; (2) a `ComponentFixture` whose root view is itself `OnPush` doesn't reliably re-check on a second `detectChanges()` call for a plain property mutation in this Angular 12 TestBed environment — adapter-spec test hosts use `Default` change detection instead (the component under test, `NgxFastMarqueeComponent`, stays `OnPush`); (3) the zone.js gap above. [`app-fast-marquee overview`](project.md) cross-references this for readers landing on the `12.x` branch. Full record: [`openspec/changes/adapt-12x-line/design.md`](../openspec/changes/adapt-12x-line/design.md) (branch-local, not archived to this bundle — see convention 10).
