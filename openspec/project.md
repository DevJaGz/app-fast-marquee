# Project

OpenSpec project context for app-fast-marquee.

## Capability organisation

Specs are split by capability:

- [`specs/library/`](specs/library/) — specs for the `ngx-fast-marquee` publishable library
- [`specs/application/`](specs/application/) — specs for the `app-fast-marquee` demo application, including its Playwright e2e suite ([`e2e/`](../../e2e/))
