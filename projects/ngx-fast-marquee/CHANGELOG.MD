# Changelog

## Version 1.0.0

### Highlights
- **New Component**: Introduced `NgxFastMarqueeInnerComponent`.
- **Performance**: Built with Angular Signals for optimized state management.
- **Improved Responsiveness**: Implemented debounce time for resize and speed change events.

### Features
- **Auto-fill**: Automatically adjusts the content to fill the available space.
- **Play/Pause Controls**:
  - Play the marquee animation seamlessly.
  - Pause on hover or click for better user interaction.
- **Styling Enhancements**:
  - Support for masking.
  - Gradient overlays for improved aesthetics.
- **Customizability**:
  - Adjustable speed and direction.
- **Server-Side Rendering (SSR)**: Ensures compatibility for SSR environments.
